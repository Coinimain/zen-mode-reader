# Zen Mode – Distraction-Free Reader

Zen Mode is a lightweight Firefox browser extension that turns cluttered articles into clean, readable pages.

## Features
- One-click reader mode
- Removes ads, sidebars, and visual clutter
- Improves readability for long-form articles
- Fast and minimal design

## Privacy
Zen Mode does **not** collect, store, or transmit any personal data.  
No tracking, no analytics, no third-party requests.
